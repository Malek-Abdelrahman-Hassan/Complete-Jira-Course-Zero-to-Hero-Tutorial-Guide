# What You'll Learn in This Course

[Course home](../README.md) › [Section 1: Introduction](README.md) › Lesson 2 · 6:34

## TL;DR

The course has ten sections that build on each other, so beginners should take them in order. It moves from Jira basics and its core building blocks through Scrum and Kanban, organizing work, JQL, boards and workflows, cross-team work, dashboards and reports, and automation, and ends with best practices. Throughout, it focuses on what a regular user can do without admin rights.

## Key concepts

- **Building blocks**: Each section relies on the ones before it. Experienced users can skip ahead, but taking the sections in order builds a complete picture of how Jira works.
- **Jira is not only for Scrum and Kanban**: Jira supports many kinds of teams, frameworks, and approaches. Section 3 concentrates on Scrum and Kanban because they are the most common.
- **JQL (Jira Query Language)**: A query language that looks a lot like SQL but reads almost like plain English. No programming background is needed. Filters written in JQL feed boards, dashboards, and dashboard gadgets.
- **Admin vs user**: In a personal practice site you are the site admin and can change anything. In most organizations only one or a few people administer Jira, so knowing what a regular user can do, including automation, matters most at work.

## Tips and pitfalls

- **Beginners: don't skip around.** Later topics such as JQL-based boards and dashboards assume the basics of spaces, work items, and boards.
- **Scale is the real challenge.** Ten or twenty work items are easy to track. Thousands need labels, components, versions, and filters (Sections 4 and 5) so that nothing gets lost.
- **Expect less access at work than in a practice site.** Organization sites usually restrict settings, so learn the options available to regular users.
