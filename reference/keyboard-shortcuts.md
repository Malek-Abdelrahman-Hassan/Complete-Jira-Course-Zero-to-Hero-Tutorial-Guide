# Keyboard Shortcuts

[Course home](../README.md) · Lesson: [Pro Tips, Shortcuts, and Smart Habits for Jira Power Users](../10-best-practices/01-pro-tips-and-shortcuts.md)

Common Jira Cloud shortcuts. Atlassian changes them from time to time, so press `?` in Jira to see the current list for your site. Shortcuts don't fire while the cursor is in a text field.

## Global

| Keys | Action |
|---|---|
| `?` | Show all keyboard shortcuts |
| `/` | Focus the search box |
| `c` | Create a work item |
| `g` then `d` | Go to dashboards |
| `g` then `a` | Go to boards |
| `g` then `i` | Go to work item search |

## On a work item

| Keys | Action |
|---|---|
| `a` | Assign |
| `i` | Assign to me |
| `e` | Edit |
| `m` | Add a comment |
| `l` | Edit labels |
| `.` | Open the actions menu |
| `Ctrl` + `Enter` (`Cmd` + `Enter` on macOS) | Submit a comment or form |

## Lists and search results

| Keys | Action |
|---|---|
| `j` / `k` | Next / previous work item |

## Shortcuts from the course

Shown in [Pro Tips, Shortcuts, and Smart Habits for Jira Power Users](../10-best-practices/01-pro-tips-and-shortcuts.md) unless another lesson is named.

| Keys | Where | Action |
|---|---|---|
| `c` | Boards, backlog, work items (not administration) | Create a work item. Check the space and work type before saving. |
| `/` | Anywhere | Jump to the search box |
| `.` | Selected work item | Open the actions menu. Items in the menu show their own letter shortcuts, and the lesson changes the status this way without the mouse. |
| `g` then `i` | Anywhere | Open work item search with the JQL editor |
| `s` then `t` | Backlog, selected work item | Send it to the top of the backlog |
| `s` then `b` | Backlog, selected work item | Send it to the bottom of the backlog |
| **Shift** + click | Backlog | Select a range of work items ([Scrum Workflow in Jira](../03-agile-scrum-and-kanban/01-scrum-workflow-sprints.md)) |
| **Ctrl** + click (**Cmd** + click on macOS) | Backlog | Add individual work items to the selection ([Scrum Workflow in Jira](../03-agile-scrum-and-kanban/01-scrum-workflow-sprints.md)) |
| Right-click a selection | Backlog | Move the selection to a sprint, to the top or bottom, or open **Bulk change** |

> [!TIP]
> On a long backlog, send every important work item to the top with `s` then `t` first, then fine-tune the order by dragging within that group.
