# Personal Study Space

Everything in this folder except this README is ignored by git, so it stays on your machine and is never published.

To start, copy [`_templates/study-log.md`](../_templates/study-log.md) to `_personal/study-log.md` and fill in the *Commitment* section. It includes a 15-session tracker that matches the [study plan](../00-start-here/study-plan.md).

Good things to keep here:

- `study-log.md`: a log of study sessions (insert `_templates/study-session.md` for each entry).
- Private notes, questions, and reflections.
- Details of your Jira sandbox site, such as its URL and test accounts.
- Your course certificate and its verification link.

Public notes should not link to files in this folder, because the links would be broken for other readers.
