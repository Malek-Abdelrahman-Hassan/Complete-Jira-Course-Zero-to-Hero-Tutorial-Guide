## How each lesson note is organized

Every lesson note uses the same layout so that reviewing is fast:

1. **TL;DR**: the lesson in a few sentences.
2. **Key concepts**: terms and ideas, with new terms added to the glossary.
3. **How to do it in Jira**: the steps and menus shown in the lesson.
4. **Examples**: realistic scenarios and sample JQL.
5. **Tips and pitfalls**: good habits and common mistakes.
6. **Review questions**: self-check questions with hidden answers.

Each section also has an overview with learning objectives, hands-on exercises, and key takeaways, plus a quiz note with original practice questions and flashcards.
